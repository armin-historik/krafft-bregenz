## Quellenkritik
Die Festschrift von 1929 ist eine Firmen-Selbstdarstellung. Der Datumswiderspruch beim Fabrikerwerb und die ungesicherte Lesart der Zeitungsanzeige von 1897 werden bewusst kenntlich gemacht.

## Bild

## Ergänzung: Areal und NS-Zeit
Die Seite `areal-heute.html` behandelt den Verkauf an Dornier 1938 und die Rückstellungsverfahren bis 1961 auf Grundlage von Peter Melichar (Historikerkommission, Band 19, S. 53–56).
